# Расписание МГСУ — beta 0.1.0

Неофициальное Android-приложение для публичного расписания НИУ МГСУ. Публичная версия остаётся **beta 0.1.0** до отдельного решения владельца проекта.

## Что исправлено в этой ревизии

- первый запуск сначала загружает и индексирует официальные PDF занятий и экзаменов, и только после успешной обработки показывает выбор «Студент / Преподаватель»;
- добавлены официальные домены/зеркала расписания, включая `www-20.mgsu.ru`;
- парсер учитывает поворот landscape-страниц PDF, разрезанные заголовки групп и разрезанные интервалы времени;
- преподаватели распознаются строго по фамилии + двум инициалам, включая записи целиком в верхнем регистре;
- старый каталог и кэш старого парсера автоматически сбрасываются (catalog schema 5 / parser 5);
- при нулевом результате теперь показывается диагностическая ошибка, а не ложное «занятий нет»;
- экран входа использует официальные сетевые ресурсы НИУ МГСУ для логотипа и фотографии кампуса;
- видимое название приложения — `Расписание МГСУ`, без слова beta;
- шестерёнка открывает экран `Настройки`;
- нижняя навигация исправлена: `Сегодня / Неделя / Месяц / Задания / Настройки`, однострочные подписи;
- GitHub Actions перед сборкой пытается заменить launcher icon на официальный PNG НИУ МГСУ; если сервер временно недоступен, сборка не блокируется.

## Версия

- `versionName = 0.1.0-beta`
- `versionCode = 13`
- `minSdk = 26`
- `targetSdk = 35`
- `compileSdk = 35`

## Сборка через GitHub Actions

Загрузите содержимое архива в корень репозитория и сделайте commit. Workflow `Build Android APK` сначала собирает APK (`assembleDebug`), затем запускает unit tests и lint как диагностические проверки. Готовый APK появляется в artifact `MGSU-Schedule-beta-0.1.0-debug`.

## Источники данных и фирменных материалов

Приложение использует только публичные официальные страницы/файлы НИУ МГСУ для расписания и официальные сетевые ресурсы университета для фирменных материалов. Приложение не является официальным приложением университета.
