# МГСУ Расписание — beta 0.1.0

Неофициальное Android-приложение для работы с публичным расписанием НИУ МГСУ. Проект остаётся **в beta**, пока владелец проекта отдельно не решит выйти из beta-стадии.

## Текущая версия

- публичная версия: **beta 0.1.0**;
- `versionName`: `0.1.0-beta`;
- внутренний `versionCode`: **12**;
- версия парсера кэша: **4**;
- схема каталога преподавателей/групп: **3**.

Повышение `versionCode` не меняет публичный номер beta: оно нужно Android для установки исправлений поверх предыдущих тестовых APK.

## Главное исправление этой ревизии

Парсер расписания сделан строгим. Он больше не должен превращать служебные подписи PDF, код специальности, номер курса или фрагмент текста в преподавателя, группу, дату или время.

Для профиля преподавателя требуется точное имя вида `Молоткова П.А.`. Для студента требуется конкретная группа вида `ИПГС 3-18`. После установки этой ревизии старые некорректные профили и старый кэш парсера автоматически игнорируются, поэтому один раз может понадобиться заново выбрать преподавателя/группу.

Дополнительно есть аварийная защита: если после изменения формата PDF парсер вдруг получает физически невозможное количество событий на один день, новые данные не принимаются вместо того, чтобы показывать десятки ложных пар.

## Контрольный пример

Для переданной контрольной таблицы `Молоткова П.А.` вторник 15 сентября 2026 года должен содержать **2 занятия**: в 11:30 и 13:00. В проект добавлен регрессионный unit-тест этого сценария. Таблица пользователя в APK не вшивается и не является источником данных приложения.

## Функции beta

Сохраняются все ранее сделанные функции: «Сегодня», неделя и календарь, экзамены/зачёты, локальные заметки и события, задания и дедлайны, несколько профилей, избранное, история изменений, уведомления, Android-виджеты, резервная копия, диагностика синхронизации, поиск, настройки цветов и экспорт в системный календарь.

## Совместимость

- Android 8.0+ (`minSdk 26`);
- `compileSdk 35`, `targetSdk 35`;
- JDK 17;
- Android Gradle Plugin 8.7.3;
- Gradle 8.9;
- Kotlin 2.0.21.

## Сборка через GitHub

1. Загрузите **содержимое ZIP** в корень репозитория с заменой старых файлов.
2. Сделайте commit.
3. Откройте **Actions → Build Android APK**.
4. Workflow сначала запускает обязательные unit-тесты парсера, затем собирает APK.
5. После успешной сборки скачайте artifact `MGSU-Schedule-beta-0.1.0-debug`.
6. Если сборка упадёт, скачайте `validation-logs-beta-0.1.0` и пришлите лог/скриншот красного шага.

## Источники и бренд

Приложение использует публичные официальные файлы расписания НИУ МГСУ. В проекте хранится официальный брендовый ресурс, чтобы сама GitHub-сборка не зависела от временной доступности сайта МГСУ. Приложение является неофициальным.
