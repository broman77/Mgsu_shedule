# МГСУ Расписание — Android

Неофициальное Android-приложение для удобного просмотра публичного расписания НИУ МГСУ.

## Что уже реализовано

- Первый запуск: **Студент / Преподаватель**.
- Для студента: институт, курс, форма обучения, группа.
- Для преподавателя: поиск по фамилии и инициалам.
- Календарь по месяцам с индикаторами дней, где есть события.
- Занятия + экзамены/зачёты.
- Учёт конкретных номеров учебных недель и чётной/нечётной недели.
- Автообновление расписания с публичных страниц НИУ МГСУ каждые 6 часов через WorkManager.
- Кнопка ручного обновления.
- Личные заметки к каждому занятию.
- Локальное удаление занятия и восстановление удалённых.
- Уведомления о расписании на завтра.
- Кнопка открытия исходного PDF МГСУ для проверки.
- Цветовая схема на основе фирменного синего НИУ МГСУ RGB 15/60/115.


## Официальные фото и логотип

В финальной GitHub-сборке фирменные материалы не генерируются ИИ. Перед компиляцией workflow скачивает:

- логотип НИУ МГСУ из ресурса `api-loft.mgsu.ru`;
- фотографию кампуса, используемую официальным сайтом `pish.mgsu.ru`.

Затем официальный логотип без изменения пропорций используется для значка приложения. Если любой официальный файл не удастся скачать, workflow завершится ошибкой вместо сборки APK с подменным изображением.

В репозитории лежат только технические нейтральные заглушки с теми же именами ресурсов; во время GitHub Actions они обязательно заменяются официальными файлами до `assembleDebug`.

## Как получить APK через GitHub

1. Создайте новый пустой репозиторий на GitHub.
2. Распакуйте этот ZIP.
3. Загрузите **содержимое** папки `MGSU-Schedule` в корень репозитория.
4. Откройте вкладку **Actions**.
5. Выберите **Build Android APK** → **Run workflow**.
6. После завершения откройте выполненный workflow и внизу скачайте Artifact **MGSU-Schedule-debug**.
7. Внутри будет `app-debug.apk`.

Никакой Android Studio для сборки через GitHub не требуется.

## Важно про автоматический разбор расписания

МГСУ публикует расписание в PDF-таблицах, а не в стабильном публичном JSON API. Приложение обнаруживает актуальные PDF на страницах занятий и экзаменов, скачивает их и разбирает по координатам текста внутри таблицы. Это существенно устойчивее простого чтения строк PDF, но если университет полностью изменит макет таблиц, парсер может потребовать корректировку. На каждой карточке есть кнопка **Источник**, чтобы открыть официальный PDF и свериться.

Для правильного расчёта чётности недели в профиле указывается понедельник первой учебной недели. Значение по умолчанию для осени 2026 — `2026-08-31`; его можно изменить при выборе профиля.
