# МГСУ Расписание — beta 0.1.0

Неофициальное Android-приложение для удобной работы с публичным расписанием НИУ МГСУ. Проект остаётся **в beta**, пока владелец проекта отдельно не решит выйти из beta-стадии.

## Что входит в beta 0.1.0

- вход как студент или преподаватель;
- автоподстановка преподавателей и групп из найденных расписаний МГСУ;
- экраны «Сегодня», «Неделя», «Календарь», «Задания» и «Ещё»;
- занятия, экзамены, зачёты, учебные недели, чётность/нечётность и отдельные номера недель;
- офлайн-кэш последнего успешно загруженного расписания;
- уведомления об изменениях, перед парами, утром и вечером;
- Android-виджеты «следующая пара» и «сегодня»;
- несколько профилей и избранные группы/преподаватели;
- личные события, заметки, локальное редактирование, скрытие и восстановление;
- подробный экран дня и недельная временная шкала;
- задания, дедлайны, ссылки и прикреплённые файлы;
- экспорт занятия/дедлайна в системный календарь Android;
- глобальный поиск по предмету, преподавателю и аудитории;
- справочник корпусов/маршрутов;
- настраиваемые цвета типов занятий;
- история изменений расписания;
- экспорт/импорт резервной копии;
- диагностика синхронизации;
- маркировка официальных, личных и локально изменённых событий.

## Совместимость

- Android **8.0+** (`minSdk 26`);
- `compileSdk 35`, `targetSdk 35`;
- Java/JDK 17;
- Android Gradle Plugin 8.7.3 + Gradle 8.9 + Kotlin 2.0.21;
- рассчитано в том числе на современные устройства с Android 16: Android 16 запускает приложения с `targetSdk 35` в режиме совместимости.
- это beta-сборка для тестирования/установки вручную; перед публикацией в Google Play потребуется перейти на `targetSdk 36`, потому что для новых приложений и обновлений это требование действует с 31 августа 2026 года.

Для beta-сборок используется отдельный **beta signing key**, лежащий в проекте. Он нужен, чтобы APK, собранные разными запусками GitHub Actions, имели одинаковую подпись и могли обновлять друг друга. Этот ключ **не предназначен для релизной версии/Google Play** и при выходе из beta будет заменён.

## Версия

- публичная версия: **beta 0.1.0**;
- `versionName`: `0.1.0-beta`;
- внутренний `versionCode`: `10` — сохранён намеренно, чтобы не создавать downgrade относительно предыдущих тестовых APK;
- все следующие beta-версии должны повышать `versionCode`.

## Как собрать APK через GitHub

1. Распакуйте ZIP.
2. Загрузите **содержимое архива** в корень репозитория GitHub с заменой старых файлов.
3. Сделайте `Commit changes`.
4. Откройте **Actions → Build Android APK**.
5. Workflow сам установит JDK 17, Android SDK 35 и Gradle 8.9, скачает официальные материалы МГСУ, затем запустит:
   - unit tests;
   - Kotlin compilation;
   - Android Lint;
   - сборку APK;
   - проверку подписи APK.
6. При успехе скачайте artifact **`MGSU-Schedule-beta-0.1.0-debug`**.
7. При ошибке скачайте **`validation-logs-beta-0.1.0`** — там будут логи тестов, компилятора, lint и сборки.

## Официальные изображения

Логотип и фотография кампуса не генерируются ИИ и не подменяются сторонними картинками. GitHub Actions скачивает их с официальных ресурсов НИУ МГСУ перед сборкой. Если официальный файл получить не удаётся, сборка останавливается.

Подробности: `OFFICIAL_ASSETS.md`.

## Важное про установку поверх старых тестовых APK

Начиная с **beta 0.1.0**, подпись beta-сборок фиксирована. Если ранее установлен APK, собранный старым workflow со случайным debug-ключом, Android может один раз потребовать удалить старую тестовую версию перед установкой beta 0.1.0. После установки beta 0.1.0 дальнейшие beta-обновления смогут ставиться поверх неё при сохранении этого beta-ключа.
