# Официальные материалы НИУ МГСУ

Приложение является неофициальным.

В репозитории используется брендовый ресурс НИУ МГСУ, ранее полученный с официального ресурса университета (`api-loft.mgsu.ru`). Он хранится внутри проекта, чтобы GitHub Actions не ломался из-за временной недоступности сайта во время сборки.

AI-сгенерированные логотипы или «похожие» версии символики в APK не используются.

Источник расписания: публичные страницы и PDF-файлы НИУ МГСУ на официальных доменах `mgsu.ru` и официальных поддоменах-зеркалах.
