# Официальные материалы НИУ МГСУ

В репозитории намеренно нет сгенерированных ИИ или «похожих» версий логотипа и фотографии кампуса.

Перед GitHub Actions-сборкой workflow получает:

- логотип: `https://api-loft.mgsu.ru/storage/files/1/9/3/193.png`;
- фотографию кампуса: `https://mgsu.ru/news/2025/02-09-2025-86800648.jpg`.

Оба адреса относятся к официальным ресурсам НИУ МГСУ. Workflow проверяет, что логотип является PNG, фотография — JPEG, и останавливает сборку при ошибке загрузки вместо использования подменного изображения.

Приложение является неофициальным. Источник материалов: НИУ МГСУ / `mgsu.ru`.
