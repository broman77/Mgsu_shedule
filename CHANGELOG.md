# Changelog

## beta 0.1.0

Первая зафиксированная beta-версия единого проекта. В неё включены все функции, согласованные на предыдущих этапах разработки. Старые промежуточные номера больше не используются как публичные версии приложения.

## beta 0.1.0 — CI hotfix
- сборка больше не зависит от загрузки логотипа/фото с сайта МГСУ во время GitHub Actions;
- брендовый ресурс включён в проект;
- APK собирается первым обязательным этапом, а unit-тесты и lint идут как дополнительные проверки beta;
- workflow возвращён к стабильной связке checkout/setup-java/setup-gradle, использовавшейся в предыдущих успешных сборках.

## beta 0.1.0 — parser hotfix
- Исправлено ложное размножение занятий преподавателя из-за поиска времени по всей странице PDF.
- Строки времени и даты теперь берутся только из левой служебной части таблицы.
- Фильтр преподавателя стал строгим по фамилии и инициалам.
- Добавлено распознавание диапазонов недель (например, 1-3,5,7-8 нед.) и числитель/знаменатель.
- Одинаковые PDF с официальных зеркал больше не обрабатываются повторно.
- Дубли одного занятия объединяются; для преподавателя объединяются группы в одном временном слоте.
- Идентификатор занятия больше не зависит от URL зеркала.
