# Changelog

## beta 0.1.0 — strict schedule parser revision

Публичная версия остаётся **beta 0.1.0**. Внутренний `versionCode` повышен до 12 только для установки обновления поверх предыдущих beta APK.

### Исправлено
- ложные профили преподавателей вроде `В-молоткова` больше не принимаются и не попадают в подсказки;
- широкие псевдогруппы вроде `ИПГС 1 курс` больше нельзя сохранить как группу — требуется конкретная группа, например `ИПГС 3-18`;
- старый кэш подсказок и старый кэш расписания сбрасываются после обновления схемы парсера;
- коды специальностей `08.03.01` больше не могут превращаться во время или дату занятия;
- обычное занятие принимается только с одним из восьми официальных диапазонов времени пар МГСУ;
- дни недели определяются по циклам номеров пар 1…8 с дополнительной проверкой подписей дня, а не по ближайшей букве вертикальной надписи PDF;
- студенту читается только точный столбец выбранной группы;
- преподавателю засчитываются только ячейки с точным совпадением фамилии и двух инициалов;
- одинаковые события из нескольких групп/официальных зеркал объединяются по физическому временному слоту;
- добавлена предохранительная проверка: результат с более чем 12 событиями у одного профиля в один день отклоняется как повреждённый, вместо показа 61/94 занятий;
- фильтрация учебных недель вынесена в единое тестируемое правило для UI, виджетов и уведомлений.
