# Статус проекта

Финальная версия проекта для первой сборки: **1.0.0**.

Готово: выбор студент/преподаватель, фильтры студента, поиск преподавателя, календарь, занятия и экзамены, учебные недели, заметки, скрытие и восстановление занятий, уведомления, автообновление и ручная синхронизация, открытие официального источника.

Фирменные фото и логотип подменяются на официальные материалы НИУ МГСУ непосредственно в GitHub Actions перед компиляцией.

Проверка реальных групп после первой установки остаётся обязательной, потому что МГСУ может менять структуру PDF-файлов расписания без сохранения прежнего формата.
