# CI fix — beta 0.1.0

Исправлена последовательность GitHub Actions:

1. Сначала обязательно компилируется APK (`:app:assembleDebug`).
2. Если приложение не компилируется, workflow останавливается именно на `Build beta APK` и показывает реальную ошибку Kotlin/Android.
3. Unit tests и Android Lint запускаются после успешной сборки как диагностические проверки beta и не блокируют публикацию APK.
4. APK загружается при успешном `Build beta APK`, даже если один из диагностических тестов требует дальнейшего исправления.

Публичная версия остаётся `beta 0.1.0`, `versionCode = 12`.
